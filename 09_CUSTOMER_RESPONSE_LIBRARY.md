# Customer Experience — Response Library

Standard: exceed Etsy's minimum response-time/resolution norms. Target first
response within a few hours during active hours, never past 24h.

## Where is my order? (digital)

"Hi [name]! Digital orders deliver automatically right after checkout — you
can grab your files anytime from Etsy under Purchases & Reviews > [order] >
Download files. If you don't see it there, it's almost always a
browser/app sync hiccup, not a problem with your order — try etsy.com on a
browser, and if it's still not showing, tell me and I'll send the files
directly, no wait needed."

## File won't open / looks corrupted

"So sorry about that — let's fix it right now. Could you tell me what app
you tried opening it in? In the meantime I'm sending a fresh copy of the
file directly to this conversation so you're not stuck waiting." (Always
resolve same-day; this is a QC failure on our end, treat it as priority one.)

## Personalization change request (pre-fulfillment)

"Of course! Just reply here with the update (name/color/format) and I'll get
your revised file to you within 48 hours as stated in the listing — usually
much sooner."

## Personalization change request (post-fulfillment, buyer changed their mind)

"Happy to help. Since this one's already custom-built, the first revision is
free — just let me know what you'd like changed. For anything beyond that
we'll figure out something fair together, but let's start with the first fix."

## Wrong format/variant purchased

"No problem at all — this happens because [listing] has a few format options
and it's easy to grab the wrong one. I'll send you the [correct format]
version directly so you don't need to navigate a refund/repurchase, unless
you'd prefer a refund instead — your call."

## Unhappy with design post-purchase (not a defect)

"I'm sorry it's not landing the way you hoped! A couple options: I can swap
you to [alternate format/edition] at no cost if that might fit better, or if
you'd rather, let's talk refund — I want you to actually get value here, not
just keep a file that doesn't work for you." (Escalate to CEO if buyer
pushes back after this — see escalation triggers in `07_OPERATIONS_SOP.md`.)

## Pre-sale question: "Will this work for [specific need]?"

Answer honestly and specifically — never oversell to close a sale. If it
genuinely won't fit their need, say so and, where relevant, point to the SKU
that actually would (including experiments #18-20 if applicable). Log the
question topic in the Voice-of-Customer tracker below regardless of outcome —
recurring "does this work for X" questions are a signal for a new SKU.

## Negative review recovery

Never ask for a review change in exchange for anything, never argue publicly.
Respond publicly once, briefly and warmly, acknowledging the issue and
inviting them to message privately to resolve it — then resolve it well
privately. Log the root cause in Voice-of-Customer.
